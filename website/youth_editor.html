Youth Data Editor

How it works:
  1. Search for a youth by last name or permission code
  2. Edit their information (birth date, parent/guardian, medical, emergency contact, signature)
  3. Click "Save Changes" to update their data
  4. Click "Download Updated JSON" to get the updated file
  5. Replace the original youth_data.json in the file_load folder
  6. Run the loader script to import into the system
